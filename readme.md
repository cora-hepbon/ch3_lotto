# 🎰 Streamlit 로또 번호 생성기

Streamlit을 기반으로 동작하는 단순하고 직관적인 로또 번호 생성기 웹 애플리케이션입니다.

---

## 📌 주요 기능

* **무작위 번호 추출**: 1부터 45 사이의 중복 없는 6개 숫자를 무작위로 생성하고 오름차순으로 정렬합니다.
* **최대 5개 세트 기록 유지**: 생성 버튼을 누를 때마다 최신 생성 번호 세트가 아래로 누적되며, 5개가 넘어가면 가장 먼저 생성된 세트가 자동으로 삭제됩니다.
* **실제 로또 공 색상 적용**:
  * `1 ~ 10`: 노란색 🟡
  * `11 ~ 20`: 파란색 🔵
  * `21 ~ 30`: 빨간색 🔴
  * `31 ~ 40`: 회색 ⚪
  * `41 ~ 45`: 초록색 🟢

## 🚀 시작하기

### 1. 사전 요구 사항
* Python 3.8 이상

### 2. 패키지 설치
프로젝트 루트 디렉토리의 터미널(PyCharm Terminal)에서 아래 명령어를 실행하여 필요한 패키지를 설치합니다.

```bash
pip install -r requirements.txt
```

### 3. 애플리케이션 실행
설치가 완료된 후 다음 명령어를 통해 Streamlit 서버를 구동합니다.

```bash
streamlit run app.py
```

명령어를 실행하면 기본 웹 브라우저가 자동으로 열리면서 로또 번호 생성기 화면이 나타납니다.
